## 1. 보안 취약점

### 치명적 — `next@14.2.35`

| 취약점                               | 내용                                                                                                   | 영향 범위                                | 패치 버전        |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------ | ---------------------------------------- | ---------------- |
| GHSA-2xp9-vwfh-vxw4 (CVSS 9.5)       | 이미지 최적화 API가 AVIF를 처리할 때 `sharp`→`libheif` 경유 **인증 없는 원격 코드 실행**               | `>= 10.0.0 < 15.5.24` → **14.2.35 해당** | 15.5.24 / 16.3.3 |
| CVE-2026-75604 (GHSA-p293-qw3h-jr36) | **Windows 파일시스템에서 구동되는 서버의 인증 없는 원격 코드 실행**. Linux/macOS는 미해당, 우회책 없음 | `>= 13.4 < 15.5.24` → **14.2.35 해당**   | 15.5.24 / 16.3.3 |

두 건 모두 2026년 8월 보안 릴리스에서 15.5.24와 16.3.3으로만 패치되었습니다. **Next.js 14.x는 EOL이라 패치 버전 자체가 발행되지 않습니다.** 공식 지원 정책상 14.x는 만료, 15.x는 Maintenance LTS(2026-10-21 종료), 16.x가 Active LTS입니다.

Windows RCE 건은 개발 환경이 Windows이므로 특히 유의해야 합니다.

### 전이 의존성 — 알려진 문제 없음

과거 CVE가 있었던 패키지들이 모두 패치 버전 이상으로 고정되어 있습니다.

## 4. 불필요한 의존성

| 패키지                   | 판정       | 근거                                                                                                                                                                     |
| ------------------------ | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `@types/bcryptjs@3.0.0`  | **제거함** | 스텁 패키지입니다. 공식 설명이 "Stub TypeScript definitions entry for bcryptjs, which provides its own types definitions" — bcryptjs 3.x가 자체 타입을 제공하므로 불필요 |
| `@types/jsonwebtoken`    | 유지       | jsonwebtoken은 자체 타입을 제공하지 않음                                                                                                                                 |
| `postcss`, `tailwindcss` | 유지       | `postcss.config.mjs`가 tailwindcss 플러그인을 사용 중                                                                                                                    |
| 나머지 전체              | 유지       | 소스에서 실제 import 확인                                                                                                                                                |

`autoprefixer`는 `postcss.config.mjs`가 참조하지 않으므로 누락이 아닙니다.

## 실제 적용한 변경

`package.json` 2건만 수정했습니다.

- `devDependencies`에서 `@types/bcryptjs` 삭제
- `prisma`: `8.0.0-rc.15` → `^7.10.0`

`next` 메이저 업그레이드는 React 19 동반 마이그레이션이 필요한 파괴적 변경이므로 임의로 손대지 않았습니다.

변경 반영에는 `pnpm install`이 필요하며, lockfile이 갱신됩니다.
