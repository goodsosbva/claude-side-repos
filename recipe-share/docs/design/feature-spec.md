# 레시피 공유 서비스 — MVP 기능 명세서

| ID  | 사용자 스토리                                                                            | 우선순위 | 예상 구현시간 |
| --- | ---------------------------------------------------------------------------------------- | -------- | ------------- |
| F01 | 방문자로서, 이메일/비밀번호로 회원가입하고 싶다, 그래야 레시피를 올릴 수 있다            | P0       | 1일           |
| F02 | 가입한 사용자로서, 로그인하고 싶다, 그래야 내 세션(JWT)이 유지된다                       | P0       | 1일           |
| F03 | 로그인한 사용자로서, 레시피(제목/재료/조리순서/사진)를 작성해 올리고 싶다                | P0       | 2일           |
| F04 | 방문자로서, 등록된 레시피 목록을 보고 싶다, 그래야 어떤 레시피가 있는지 알 수 있다       | P0       | 1일           |
| F05 | 방문자로서, 레시피 상세(재료/조리순서/사진)를 보고 싶다, 그래야 실제로 따라 만들 수 있다 | P0       | 1일           |
| F06 | 작성자로서, 레시피에 사진을 첨부하고 싶다(로컬 저장), 그래야 완성 사진을 보여줄 수 있다  | P0       | 1일           |
| F07 | 작성자로서, 내가 쓴 레시피를 수정/삭제하고 싶다, 그래야 잘못 올린 걸 고칠 수 있다        | P1       | 1일           |
| F08 | 로그인한 사용자로서, 내 프로필에서 내가 올린 레시피 목록을 모아보고 싶다                 | P1       | 1일           |
| F09 | 방문자로서, 제목/재료로 레시피를 검색하고 싶다, 그래야 원하는 요리를 빨리 찾는다         | P1       | 1일           |
| F10 | 서비스 운영자로서, 비로그인 사용자의 작성/수정/삭제 요청은 차단하고 싶다                 | P1       | 0.5일         |
| F11 | 사용자로서, 마음에 드는 레시피에 좋아요를 누르고 싶다, 그래야 나중에 다시 찾기 쉽다      | P2       | 1일           |
| F12 | 사용자로서, 레시피에 댓글을 남기고 싶다, 그래야 후기를 공유할 수 있다                    | P2       | 1.5일         |
| F13 | 방문자로서, 카테고리(한식/양식 등)로 레시피를 필터링하고 싶다                            | P2       | 1일           |
| F14 | 운영자로서, 이미지 저장소를 로컬에서 S3로 교체하고 싶다, 그래야 배포 확장성이 생긴다     | P2       | 1일           |

## 요약

- P0(필수, MVP 최소 동작): 7일
- P1(초기 사용성): 3.5일
- P2(MVP 이후): 4.5일

> F10(비로그인 접근 차단)은 별도 기능이 아니라 F01~F03 API에 붙는 가드입니다. 구현 시 별도 작업으로 미루지 말고 해당 API 작업에 포함하는 것을 권장합니다.
